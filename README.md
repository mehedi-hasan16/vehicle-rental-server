### Project Name & Live URL

Project Name: Vehicle Rental Server
Live URL: https://vehicle-rental-server-olive.vercel.app

### Features

**1. Authentication:**
JWT authentication, bcryptjs

**2. Vehicle Management:**
Add, update, delete vehicles, get by id, get all vehicles

**3. User Management:**
sign up and update existing user

**4. Booking System:**
Create bookings, update booking

**5. Database:**
PostgreSQL database for secure and scalable storage

### Technology Stack

Express.js, Node.js + TypeScript, jsonwebtoken, bcryptjs, PostgreSQL (pg), tsx, TypeScript, dotenv

### Setup & Usage Instructions

1. Clone the Project at https://github.com/mehedi-hasan16/vehicle-rental-server.git
2. Install Dependencies -> npm install
3. Create .env File
   ```
   PORT=5000
   DATABASE_URL=your-database-connection-url
   JWT_SECRET=your_secret_key
   ```
4. Start the Server (Development) -> npm run dev
5. Build for Production -> npm run build
